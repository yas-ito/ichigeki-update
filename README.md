# 一撃極 ICHIGEKI — 更新情報

Premiere Pro 用プラグイン「一撃極」のパネルが、**最新版があるかどうかだけ**を見に来るための置き場所です。

- 本体（購入・ダウンロード）: https://yas-tools.booth.pm/items/8705448
- パネルが読むファイル: [`version.json`](version.json)

## version.json の見かた

| 鍵 | 意味 |
|---|---|
| `latest` | 最新版の番号。**OS別が無いときに使われます**（下記） |
| `mac` / `win` | **OSごとの最新版。**あればこちらが優先されます |
| `url` | 「開く」で案内する配布ページ |
| `notes` | 一言の説明（空でもよい）。ポップアップに出ます |

🔴 **mac版とwin版は別々に出るので、OSごとに分けています。**
共通の `latest` だけにすると、Windows版がまだ 1.0.1 のときに
Windowsの人へ「1.0.2 があります」と案内してしまい、**落とせない版を教えることになります。**
`url` と `notes` も OS別に上書きできます。

## 新しい版を出したときの手順

1. BOOTH に新しい ZXP を上げる
2. **このファイルの、上げたOSの `latest` を書き換える**（`notes` も要れば1行）
   - mac版だけ出したなら `mac.latest` だけ
   - 両方出したなら `mac.latest` と `win.latest` の両方（`latest` も揃えておくと安全）
3. 以上。パネルは次の起動時に気づきます

⚠️ `latest` を先に上げるとダウンロードできない版を案内することになるので、**BOOTHが先**。
⚠️ 反映まで**数分**かかります（GitHubのキャッシュ）。すぐ出なくても正常です。
